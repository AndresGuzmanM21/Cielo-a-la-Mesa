# 🌤️ Cielo a la Mesa
## Hackaton

Una aplicación web desarrollada para un restaurante, donde los usuarios pueden visualizar el menú, explorar las diferentes categorías de productos y realizar pedidos mediante un carrito de compras con una interfaz moderna e intuitiva.

---

## 📖 Descripción

**Cielo a la Mesa** es un proyecto web orientado a ofrecer una experiencia sencilla para la gestión de pedidos de un restaurante. La aplicación permite a los usuarios navegar entre las diferentes categorías del menú, agregar productos al carrito y consultar información del establecimiento.

El proyecto fue desarrollado utilizando tecnologías web, aplicando buenas prácticas de organización del código y diseño responsivo.

---

## ✨ Funcionalidades

- 🍽️ Visualización del menú del restaurante.
- 🥩 Categorías de comida.
- 🥤 Categorías de bebidas.
- 🍰 Sección de postres.
- 🛒 Carrito de compras.
- 💬 Página para comentarios de los clientes.
- 📱 Diseño adaptable para dispositivos móviles.
- 🎨 Interfaz moderna utilizando Bootstrap.

## 🚀 Instalación

1. Clona el repositorio.

```bash
git clone https://github.com/AndresGuzmanM21/Cielo-a-la-Mesa.git
```

2. Entra en la carpeta del proyecto.

```bash
cd Cielo-a-la-Mesa
```

3. Abre el proyecto en **Visual Studio Code**.

4. Ejecuta `index.html` directamente en el navegador o utiliza la extensión **Live Server**.
